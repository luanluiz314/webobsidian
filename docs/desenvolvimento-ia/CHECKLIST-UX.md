# Checklist UX — WebObsidian (adaptado de shadcn/ui + UI UX Pro Max)

- [ ] Tema escuro é padrão, com contraste suficiente e opção de tema claro.
- [ ] Componentes e rótulos visíveis estão em português brasileiro; textos de notas não são traduzidos.
- [ ] A navegação funciona com teclado, foco visível e nomes acessíveis.
- [ ] Botões possuem área de toque adequada no Safari do iPhone.
- [ ] Layout responsivo sem cortes em larguras de 375, 768, 1024 e 1440 pixels.
- [ ] Há suporte a zoom, texto ampliado e `prefers-reduced-motion`.
- [ ] Carregamento, estado vazio, erro e sincronização exibem feedback claro.
- [ ] A interface não incentiva duas cópias conflitantes do mesmo cofre.
- [ ] Acessibilidade e contraste são verificados manual e automaticamente quando possível.
- [ ] Performance e tamanho do bundle são revistos após adicionar dependências.
